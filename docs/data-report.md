# Разведка данных

Файлы: `data/original/character_problems.json` (выгрузка), `data/original/incidents_attributes.json` (описание полей).

## Общее
- JSON-массив, **44 инцидента**, у каждого 46 полей, `id` уникален (`INC0000219xxxxx`). Все `incType = "МИ"`.
- Данные выдуманные: 5 продуктов («Автопросматриватель TicTok», «Акваланг для муравьев», «Летающий ковер»,
  «Страхование хомячков», «Вечная зажигалка»), 15 сервисов, 30 сценариев, 22 команды.

## Даты
- Формат ISO UTC: `2026-11-08T12:02:29Z`, у части `deadline` микросекунды (`...02.472263Z`). Описание полей врёт («YYYY-MM-DD HH:MM:SS»).
- `submitDate`: 2026-11-08 03:42 … 2026-11-10 20:41. Самая поздняя дата в файле — 2026-11-11 12:30 (принимаем за момент выгрузки).
- `deadline`: 2026-11-08 … 2026-11-24; `null` у 3 инцидентов на исследовании.
- Срок по приоритету, похоже: Высокий ≈ 6 ч, Средний ≈ 12 ч, Низкий ≈ 1,5–14 дней.
- `completionDate` заполнен у 20 (все решённые/закрытые/исследование), у активных — `null`.
- `waitingExitDate` всегда `0001-01-01T00:00:00` — пустое значение .NET.

## Прочее
- `solution` заполнен почти у всех, **включая активные** — шум, показываем только у решённых.
- Связи: `isMaster` 5, `isDouble` 2, `isReason` 4, `isEffect` 2, `isRootIncident=false` 4. Связки по id в файле нет — только флаги.
- `productUrl`, `eliminationType*` — всегда `null`. Ссылки в ITSM в данных нет → шаблон `ITSM_URL_TEMPLATE`.
- `receivingChannel`: «Анонимное письмо», «Жалоба от народа», «Мониторинг 9го королевства».
